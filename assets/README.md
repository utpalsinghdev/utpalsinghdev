# Asset sources

Profile panels and contact buttons are authored for this profile. Layout reference: [Marve10s](https://github.com/Marve10s/Marve10s).

Repository logos are used to identify their respective projects:

- [OpenConcho favicon](https://github.com/offendingcommit/openconcho/blob/main/packages/web/public/favicon.svg)
- [Executor icon](https://github.com/UsefulSoftwareCo/executor/blob/main/assets/executor-icon.png)
- [Wiki-Web icon](https://github.com/utpalsinghdev/wiki-web/blob/main/public/wiki-web-icon.png)

Technology icons come from [Simple Icons v16](https://github.com/simple-icons/simple-icons/tree/16.0.0), distributed under CC0. Brand names and logos remain subject to their respective trademark policies. Icons are embedded in SVG panels so rendering does not depend on external image requests.
